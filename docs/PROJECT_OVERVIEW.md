# Project Overview

| Item | Detail |
|---|---|
| Project | SauceDemo QA Automation |
| Type | Independent portfolio project (not company employment) |
| Application under test | SauceDemo, public demo e-commerce site |
| Role | QA Engineer: test design, automation, documentation |
| Tools | Playwright, JavaScript, Node.js, GitHub, GitHub Actions |

## Objective
Validate the main customer journey (login, browse, cart, checkout) with a maintainable automated
regression suite and professional QA documentation.

## Approach
1. Analyse the application and derive scenarios (`TEST_SCENARIOS.md`).
2. Write the test plan and test cases (`TEST_PLAN.md`, `test-cases.csv`).
3. Automate with Playwright using the Page Object Model, fixtures and data-driven tests.
4. Execute locally and in CI, then record real results and any real defects.

## Deliverables
Automation source code, test plan, scenarios, test cases (CSV), bug report template and log,
execution report, summary report, and a GitHub Actions pipeline.
